# Snake

Gra w węża w panelu obok rozmowy, na czas czekania na Claude'a. Gra się, gdy Claude pracuje, i staje, kiedy skończy.

## Jak używać

- `/snake` włącza i wyłącza grę (albo `/snake on`, `/snake off`).
- Kliknij panel, żeby grać. Sterowanie: strzałki albo WASD. `Esc` oddaje klawiaturę.
- Najlepszy wynik zostaje zapamiętany, a w trakcie gry widać go też przy spinnerze.

Panel potrzebuje miejsca: najlepiej szerokie okno terminala albo aplikacja Desktop.

Na podstawie moda Snake z [hamzafer/claude-code-mods](https://github.com/hamzafer/claude-code-mods), licencja MIT (plik `LICENSE`).

Wymaga Claude Code 2.1.287+ w terminalu albo 2.1.286+ w aplikacji Desktop. Brak zależności.
